# Limites de segurança

Segredos são runtime-only: nunca entram no executável, Git, documentação ou artifacts.
Credenciais de servidor, billing, ads, SMTP, DeepL, NVIDIA e signing pertencem somente a
serviços/operadores autorizados.

O sistema falha fechado para provider, licença, fonte ou artefato inválido. Logs e artifacts
não devem conter OCR, tradução, Authorization, Bearer ou tokens.
