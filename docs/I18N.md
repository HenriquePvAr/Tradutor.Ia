# Interface internationalization

The UI language layer lives in `static/i18n/`.

Supported language options:

- `auto`
- `pt-BR`
- `en-US`
- `es-ES`
- `fr-FR`
- `ja-JP`
- `ko-KR`

The selected language is stored in `localStorage` under `tradutor.interfaceLanguage`. `auto` follows the browser language and falls back to `pt-BR`.

## Catalog rules

- Each catalog must provide the same keys as `pt-BR`.
- Missing keys fall back to `pt-BR`, but tests should fail if a shipped catalog is incomplete.
- DOM translation uses `textContent` and selected safe attributes only.
- Runtime code should call `window.TradutorI18n.t(key, params)` instead of embedding raw translation keys in user-visible text.

## Formatting

`window.TradutorI18n.formatNumber(value)` and `window.TradutorI18n.formatDate(value, options)` use `Intl` with the currently resolved locale.
