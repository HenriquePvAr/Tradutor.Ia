**Vazio hoje.** Nenhuma captura foi feita: as telas reais só existem depois do login em um
ambiente configurado, e capturá-las exigiria expor dados de conta. Nenhuma imagem foi
fabricada ou simulada.

## Regras para adicionar imagens aqui

Ver [Política de Documentação §6](../../DOCUMENTATION_POLICY.md#6-quando-as-capturas-de-tela-devem-mudar).

- Capturar **somente a UI atual**;
- Recorte sensato, texto legível;
- **Zero** senha, chave de API, token, cookie, identificador privado ou e-mail pessoal;
- Nenhum caminho local de desenvolvedor sem sanitização;
- Legenda descritiva no guia, sempre;
- Nome de arquivo estável e descritivo (`acesso.png`, `nova-traducao.png`,
  `progresso-pipeline.png`, `revisao-paginas.png`, `revisao-qualidade.png`,
  `biblioteca.png`, `resultado-pdf.png`);
- **Nunca fabricar** uma captura.
